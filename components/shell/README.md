# Каркас приложения (AppShell)

Единая навигация для административного раздела. Монтируется в `app/admin/layout.tsx`,
поэтому все страницы `/admin/*` получают меню автоматически — дублировать его в
страницах больше не нужно.

## Информационная архитектура

Пять групп вместо двенадцати плоских пунктов:

| Группа | Разделы |
|---|---|
| **Оперативно** | Панель (одна страница `/admin` с вкладками «Разовые · Самовыходы · Ушедшие») |
| **Ученики и классы** | Ученики · Классы · «1-4 СВ и Дов.» |
| **Дисциплина** | Нарушения · Статистика нарушений · ВШУ · Прогульщики |
| **Аналитика** | Отсутствия |
| **Администрирование** | Персонал |
| **Аккаунт** | На главную · Тема · Выход |

Названия самих разделов сохранены прежними; изменились только подписи групп.

## Раскладка по ширинам

| Ширина | Навигация | Шапка |
|---|---|---|
| < 768 | нижний таб-бар: Панель · Ученики · Нарушения · Аналитика · Ещё | заголовок + тема |
| 768–1023 | sidebar 72px (иконки, подсказка при наведении) | заголовок + тема |
| ≥ 1024 | sidebar 240px с подписями и группами; можно свернуть | заголовок + тема |
| ≥ 1440 | то же, контент ограничен 1440px | то же |

Второстепенное — в «Ещё»: полноэкранный сгруппированный список на мобильном.

## Файлы

| Файл | Роль |
|---|---|
| `nav-config.ts` | **единственный источник правды**: пункты таб-бара, дерево групп, заголовки, фильтр по ролям, определение активного пункта |
| `AppShell.tsx` | каркас: sidebar + шапка + `main` + таб-бар + «Ещё», skip-link, отступы под фиксированную навигацию |
| `Sidebar.tsx` | навигация планшета/десктопа, сворачивание, тема, выход |
| `TabBar.tsx` | мобильный таб-бар: 5 пунктов, активный — акцент + индикатор |
| `MoreSheet.tsx` | экран «Ещё»: группы, тема, выход |
| `header-actions.tsx` | действия страницы в шапке: `useHeaderActions(() => <Button/>, [deps])` |

## Действия в шапке

Шапка принадлежит каркасу, поэтому кнопки страницы регистрируются через контекст:

```tsx
useHeaderActions(
  () => <Button onClick={refresh} leftIcon={RefreshCw}>Обновить</Button>,
  [refresh],
);
```

При размонтировании страницы действия снимаются — в шапке не остаётся кнопок
предыдущего экрана. Так сделана кнопка «Обновить» на панели: она в шапке, а не в теле.

## Как добавить раздел

1. Добавить пункт в `NAV_GROUPS` (и в `TAB_BAR_LINKS`, если он должен быть в таб-баре).
2. Создать страницу по адресу из `href`.
3. Если у страницы свой заголовок — ничего не делать: каркас не дублирует шапку.
   Если переводите страницу на каркас — добавить её в `SHELL_HEADER_ROUTES`
   и убрать собственный заголовок.

```ts
export const SHELL_HEADER_ROUTES: Record<string, string> = {
    "/admin": "Панель",
    // "/admin/reports": "Отчёты",
};
```

## Правила

- **Навигация только через `nav-config`** — иначе мобильный и десктопный варианты разойдутся.
- Пункт с `roles: ["ADMIN"]` скрывается у остальных ролей (фильтр в `filterByRoles`).
- Активный пункт определяется `isLinkActive`: `exact` — только точное совпадение
  (корень раздела), иначе — совпадение или вложенный путь.
- Шапка каркаса (sticky) и шапка страницы не должны дублировать друг друга:
  на данный момент шапку рисует либо каркас, либо страница.
- Тап-таргеты: пункт таб-бара 56px, пункт сайдбара 44px, пункт «Ещё» 56px.
- Safe-area: таб-бар использует `pb-safe`, чтобы не заезжать под системную полосу iOS.

## Переходный период

Страницы `/admin/violations`, `/admin/students`, `/admin/truants`, `/admin/absent`,
`/admin/classes`, `/admin/users`, `/admin/school-records`, `/admin/classes-overview`
пока сохраняют собственный заголовок и старую стилистику внутри каркаса.
Это осознанно: навигация уже общая, а содержимое переводится на UI Kit поэтапно
(этапы 3–4). Признак завершения перехода — пустой список `hasOwnHeader`.

## Что осталось

- Перевести страницы на `PageHeader` из UI Kit и убрать их собственные шапки.
- Глобальный поиск в шапке (ученик/класс) — требует общего эндпоинта.
- Крошки для вложенных экранов (портфолио ученика, карточка класса).
- Каркас для учительского раздела `/` (сейчас только админский).
